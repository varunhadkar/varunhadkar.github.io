FAQ

Questions

Is there really no limit on users?

Yes. One license covers one SHIP Server with as many user accounts and groups as you need. The SHIP Transfer app is free to install on every computer.

Where are our files stored?

On your own SHIP Server, in the storage folder you choose: a local drive, a NAS mount or a cloud machine's disk. Files never pass through our systems.

Why is SHIP faster than a normal upload?

Browsers and most tools use TCP, which slows down sharply over long distances and when a few packets are lost. SHIP's own UDP protocol keeps sending at the speed your connection allows and repairs only the missing pieces.

What if UDP is blocked on a network?

SHIP Transfer notices within a few seconds and switches to SHIP over TCP, then to HTTPS if needed. The transfer continues without the user doing anything.

What do I need to run SHIP Server?

A 64-bit Windows 10/11 or Windows Server 2016+, macOS 11+ or a modern Linux machine, with enough disk for your files. For people outside your office, the server needs a public address or router port forwarding. The docs walk you through it.

Is the macOS app ready?

The macOS installers are currently in beta. Windows and Linux are fully released.

What happens after a year?

Renew to keep running SHIP Server and to receive updates. Your files always stay yours.
