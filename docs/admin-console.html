Restart service applies configuration changes; transfers pause for a few seconds and resume. Shut down service stops SHIP completely until it's started again on the server (Windows: Start menu › SHIP Server › Start SHIP Server; Linux: sudo systemctl start ship-server).

Security features

  • Separate admin console on its own port, administrators only
  • Two-factor sign-in (authenticator app) for any user; can be required for administrators
  • Account lock-out after repeated failed sign-ins
  • Per-user and global allowed and blocked IP addresses
  • Antivirus scanning of uploads with ClamAV and a quarantine
  • Full audit log

Backups

Back up two things regularly:

  1. The data folder (users, permissions, settings, history), which is small.
  2. The storage folder, which holds your files.

Default data folders: Windows C:\ProgramData\SHIP Server (or the folder you chose), macOS /Library/Application Support/SHIP Server/data, Linux /var/lib/ship-server.

Logs

The server log is logs/ship-server.log inside the data folder (Windows: Start menu › SHIP Server › Server logs). On Linux also journalctl -u ship-server.

Forgot the admin password

On the server, run as administrator/root:

# Windows (in the SHIP Server program folder)
ship.exe reset-password --data "C:\ProgramData\SHIP Server" --user admin
# Linux
sudo /opt/ship-server/ship reset-password --data /var/lib/ship-server --user admin
