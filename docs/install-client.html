Install SHIP Transfer

Install the free SHIP Transfer app and connect it to your organisation's server. It takes about two minutes.

Before you start, have the server address, your user name and your password ready. Your administrator sends you these.

Windows

  1. Download SHIP-Transfer-Setup-Windows.exe and double-click it.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. Click Next and accept the license agreement.
  4. Connect to your SHIP server: type the server address and click Test connection. You should see Connected to …. (No address yet? Leave it empty; the app asks later.)
  5. Download folder: choose where downloaded files are saved. The default is Downloads\SHIP.
  6. Options: keep Start when I sign in to Windows ticked so transfers keep running in the background.
  7. Click Install, then Finish. SHIP Transfer opens. Sign in.

No administrator rights are needed. SHIP Transfer is installed for your Windows account only.

macOS Beta

  1. Download SHIP-Transfer-macOS.pkg.
  2. Double-click it. If macOS says it can't be opened because it is from an unidentified developer:
    • macOS 14 and earlier: right-click (or Control-click) the file, choose Open, then Open again.
    • macOS 15 and later: open System Settings › Privacy & Security, scroll down and click Open Anyway next to the SHIP message.
  3. Follow the installer: Continue, Agree, Install, then enter your Mac password.
  4. SHIP Transfer opens automatically and walks you through setup (see First run).

Alternative: your server's user portal (SHIP Transfer app page) shows a one-line Terminal command that installs the app without the security prompt.

Linux

Ubuntu, Debian, Linux Mint: download the .deb file and double-click it to open it in the Software app, then click Install. Or in a terminal:

sudo apt install ./SHIP-Transfer-Linux-amd64.deb

Fedora, RHEL, openSUSE:

sudo dnf install ./SHIP-Transfer-Linux-x86_64.rpm

Then open SHIP Transfer from your applications menu. Install zenity if your desktop doesn't already include it; the app uses it for folder pickers.

First run: the setup wizard

The first time SHIP Transfer opens (unless the Windows installer already asked), it guides you through three steps.

  1. Server address: type what your administrator sent and click Connect. Port 8090 is added for you.
  2. Download folder: click Choose… to pick where downloads are saved.
  3. Sign in with your user name and password. If your account uses two-factor authentication, you'll also be asked for a 6-digit code.

If your administrator asks you to change your password on first sign-in, you'll be asked once, right after signing in.

Updating

Download the latest installer and run it. Your settings and sign-in are kept.

Uninstalling

  • Windows: Settings › Apps › SHIP Transfer › Uninstall.
  • macOS: drag SHIP Transfer from Applications to the Bin, then run sudo rm /Library/LaunchAgents/app.ship.transfer.plist.
  • Linux: sudo apt remove ship-transfer or sudo dnf remove ship-transfer.

Files you downloaded are never removed.
