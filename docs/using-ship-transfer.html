Using SHIP Transfer

Browse your folders, upload and download files and folders, and keep an eye on every transfer.

Locations

The left sidebar lists the places you can use:

  • My Files: your personal folder, if your administrator gave you one.
  • Shared Folders: everything shared with you. Each shared folder is also listed on its own.
  • Group spaces: folders that belong to a group you are in.

You only see the folders you're allowed to use. Double-click a folder to open it; use the path at the top to go back.

Uploading

  • Click Upload to choose files, or Upload Folder to send a whole folder with everything inside it.
  • Or simply drag files and folders from Explorer, Finder or your file manager onto the window.

Uploads go into the folder you have open. If the Upload buttons are greyed out, you don't have upload permission in that folder; ask your administrator.

Downloading

  • Double-click a file, or select files and folders and click Download (also on the right-click menu).
  • Downloads are saved in your download folder and keep their folder structure.
  • Click the magnifier next to a finished download to show it in Explorer or Finder.

The Transfers panel

  • Shows the live speed, a speed graph and every upload and download.
  • Pause, resume or cancel each transfer. Failed transfers can be retried and continue where they stopped.
  • A badge shows how the transfer travels: UDP (fastest), TCP (used when UDP is blocked) or HTTPS.
  • You can close the window; transfers keep running in the background.

Speed test

At the bottom of the Transfers panel, choose a size and click Run to measure upload and download speed to your server.

Settings

Click the gear icon next to your name to change your download folder, choose to be asked where to save each download, limit the speed, or set how many transfers run at once. The arrow icon signs you out.

Using a browser instead

Open the server address in any browser to use the web portal. You can browse, upload, download, create share links and manage your account (including two-factor sign-in). Browser transfers use HTTPS, which is slower over long distances than the app.

Share links

In the web portal, select a file or folder and choose Share to create a download link for someone without an account, with optional password, expiry date and download limit. An upload link lets an outsider drop files into a folder. Share links need the Create share links permission.

Command line

SHIP Transfer also installs the ship command, which is useful for scripts and scheduled jobs.

ship login http://files.company.com:8090 -u maya
ship ls /Projects
ship push "D:\Footage\Day1" /Projects/Day1 --verify
ship pull /Deliveries/Trailer.mov "D:\Downloads"
ship sync "D:\Projects" /Projects --mode both --interval 60s

Add --tcp or --https to force a transport. Run ship help for every option.
