Install SHIP Server

Install SHIP Server on the computer that will store your files, then finish the short setup in the admin console.

The SHIP Server installer is delivered with your license. Request a license if you don't have it yet.

Requirements

Minimum
Operating systemWindows 10/11 or Windows Server 2016+ (64-bit) · macOS 11+ · Linux with systemd (Ubuntu 20.04+, Debian 11+, RHEL/Rocky 8+, Fedora)
Processor and memory2 CPU cores, 2 GB RAM. More cores help with many simultaneous transfers.
DiskAbout 50 MB for SHIP, plus space for your files in the storage folder.
NetworkFor users outside your network: a public IP address or router port forwarding (see Network and ports).

The computer should stay on and not go to sleep while people use SHIP.

Windows

  1. Double-click SHIP-Server-Setup-Windows.exe and allow it to make changes.
  2. Program folder: where SHIP is installed (small, about 35 MB).
  3. SHIP data folder: holds the user database, settings and logs. Back it up. Already used SHIP on this computer? Choose the existing data folder and all users, folders and settings are kept.
  4. Storage folder: where uploaded files are kept. Setup suggests the drive with the most free space.
  5. Options: keep Allow through Windows Firewall ticked so people can connect. The desktop shortcut is optional.
  6. Click Install. SHIP Server is installed as a Windows service that starts with the computer.
  7. Click Finish to open the admin console and complete first-time setup.

The Start menu gets a SHIP Server folder with the admin console, start and stop shortcuts and the server logs.

macOS Beta

  1. Double-click SHIP-Server-macOS.pkg. If macOS blocks it, use right-click › Open (macOS 14 and earlier) or System Settings › Privacy & Security › Open Anyway (macOS 15+).
  2. Follow the installer and enter your Mac password.
  3. SHIP Server starts automatically at boot. SHIP Admin Console is added to Applications and opens when installation finishes.

The default storage folder on a Mac is /Users/Shared/SHIP Storage. In System Settings › Energy, turn on Prevent automatic sleeping.

Linux

# Ubuntu / Debian
sudo apt install ./SHIP-Server-Linux-amd64.deb
# Fedora / RHEL / Rocky
sudo dnf install ./SHIP-Server-Linux-x86_64.rpm

The package installs SHIP to /opt/ship-server, stores data in /var/lib/ship-server, proposes /srv/ship-storage for files and starts the ship-server systemd service. If ufw or firewalld is active, the needed ports are opened.

sudo systemctl status ship-server     # is it running?
sudo journalctl -u ship-server -f      # live log

First-time setup

Open the admin console: http://localhost:9090/admin on the server itself (on Windows and macOS it opens for you). A four-step wizard appears:

  1. Welcome. From another computer you'll be asked for a setup code; it's in setup-code.txt in the data folder. On the server itself no code is needed.
  2. Administrator account: server name, admin user name and a password (at least 8 characters).
  3. Storage folder: confirm or change where files are stored. The folder is created if needed.
  4. Done: open the admin console.

Next: create shared folders and users, then check Network for the address to send your users.

Upgrading

Run the newer installer on the server. The service stops briefly, is updated and starts again. Users, folders, settings and files are kept. On Linux, install the newer package the same way.

Uninstalling

  • Windows: Settings › Apps › SHIP Server › Uninstall.
  • macOS: sudo "/Library/Application Support/SHIP Server/uninstall.sh"
  • Linux: sudo apt remove ship-server / sudo dnf remove ship-server

Uninstalling never deletes your data folder or your stored files.
